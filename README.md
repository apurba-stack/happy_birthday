# Birthday Surprise Website for Gungun

This is a fully responsive, visually aesthetic static website built as a birthday surprise for Gungun (Ashmita Dey).

## 🚀 How to set up your assets

To make the website fully functional, you need to add your images and music to the `assets` folder.

### 1. Photos
Put your photos in `assets/images/`.
The website is currently looking for these files:
- `img1.jpg`, `img2.jpg`, `img3.jpg`, `img4.jpg` (for the background carousel)
- `mem1.jpg`, `mem2.jpg`, `mem3.jpg` (for the memories section)

*Note: If your file names or extensions (e.g., .png) are different, update them in `index.html`.*

### 2. Music
Put a soft instrumental or piano track in `assets/music/` and name it `soft-bgm.mp3`.

## 🛠 Features
- **Reveal Button:** Initially shows only a "Click here" button over a beautiful background slideshow.
- **Glassmorphism:** Modern, soft UI design using blurred overlays.
- **Responsive:** Optimized for mobile, tablet, and desktop.
- **Surprise Interaction:** Triggers a confetti explosion and a sweet message.
- **Smooth Animations:** Sections fade in as you scroll.
- **Music Toggle:** Control the background music with a floating button.

## 🌐 Deployment
This website is ready to be deployed on **Netlify**. 
Simply drag and drop the project folder onto the Netlify dashboard.
